## 0. 절대 원칙 (충돌 시 이게 이긴다)

### 0.1 리스크 헌법 (주식 MDD 10%와 **별개**)

| 항목 | Bitget 규칙 | 주식(KR/US)과 관계 |
|------|-------------|-------------------|
| **Portfolio NAV MDD** | **−30% halt / −20% 신규차단 / −15% 사이즈축소** (목표 SSOT) | 숫자·로직 **공유 금지** |
| **그룹 MDD** | 그룹별 −30% (현행 legacy) | 주식 tier·governor **import 금지** |
| **실전 매매** | `ENABLE_REAL_EXECUTION=false` **기본 유지** — P2-5 체크리스트 전까지 **절대 true 금지** | 주식 실매매와 **무관** |
| **수익 목표** | **듀얼 북극성** — 아래 §0.4 (주식 10%/40~70% vs Bitget 5%/연 12~25%) | 주식·Bitget **숫자 혼용 금지** |

- **충돌 시 우선순위**: (1) 실전 스위치 OFF (2) Portfolio MDD (3) execution_safety 13-gate (4) 그 외 Kelly·쿼터
- 지금까지 문제: **그룹 단위** 방어만 있고 **계좌 전체 NAV** 선제 차단이 약함 → **묶음A**에서 고친다.
- **A-1 현행 tier (−15/−20/−30%)** = audit P0-2 **1차 구현** · **Bitget 5% 프로필**은 별도 튜닝 단계(§0.4 Track B).

### 0.4 듀얼 북극성 — 수익·MDD 목표 (2026-08-03 · Claude Pro + 디렉터 합의안)

> **원칙**: 두 트랙은 **서버·DB·config 완전 격리**. 한쪽 숫자를 다른 쪽에 복사하지 않는다.  
> **Calmar** = 연복리(CAGR) ÷ 최대낙폭(MDD) — 목표 밴드 설정용 참고치.

| 트랙 | 대상 | MDD 하드캡 (어느 장세든) | 연복리 북극성 | Calmar (참고) | 현재 단계 |
|------|------|-------------------------|---------------|---------------|-----------|
| **A · 주식** | KR/US `dante-factory` | **−10%** | **40~70%** | 4.0~7.0 | 주식 로드맵 SSOT |
| **B · Bitget** | `bitget/` 코인 paper→파일럿 | **−5%** | **12~25%** (단계형, 아래) | 2.4~5.0 | paper 관측·구조 완성 중 |

#### Track B · Bitget — MDD 5%에 맞는 연복리 (구조 대입)

Claude Pro 판단: **어느 장세든 MDD 5% 초과 금지**는 타당. **현재 paper 수익률을 그대로 유지**하며 5% MDD를 지키기는 **어렵다** → 리스크를 줄이면 수익도 비례해 내려가는 것이 정상.

| Bitget 단계 | 기간(가이드) | 연복리 목표 | MDD 캡 | 전제 (우리 구조) |
|-------------|-------------|------------|--------|------------------|
| **B0 · 검증** | 지금~`06` 2~4주 | **측정만** (목표 % 없음) | 설계 5% | A·B 1단계 코드 · 4-track 관측 · forward_trades 적재 |
| **B1 · 보수** | `06` 통과 후 6~12개월 | **12~18%** | **5%** | A tier **5% 프로필** 튜닝 · Kelly↓ · lev≤3 · alloc shadow→prod Go/No-Go |
| **B2 · 기본** | 12~24개월 | **18~25%** | **5%** | C-2 funding PnL · C-1 bad tick · deathmatch alloc prod · B-3 WF block 검토 |
| **B3 · 스트레치** | 24개월+ · P2-5 후 | **25~35%** | **5%** | 실전 parity · 유동성 캡(P2-2) — **달성 보장 없음** |

**5% MDD를 코드에 대입할 때 (미래 Handoff · 지금 미적용)**

| 레버 | 현행(A-1 1차) | Track B 5% 프로필 (안) |
|------|--------------|----------------------|
| `PORTFOLIO_MDD_REDUCE` | 15% | **~3%** |
| `PORTFOLIO_MDD_BLOCK` | 20% | **~4%** |
| `PORTFOLIO_MDD_HALT` | 30% | **5%** |
| `DYNAMIC_KELLY_RISK` | ~1% | **~0.3~0.5%** (측정 후) |
| `MAX_LEVERAGE` | 5 | **2~3** |
| deathmatch alloc | OFF (shadow) | loser **굶기기** ON (Go/No-Go 후) |

**지금 할 일 vs 나중**: B0(관측)만 — **5% tier 튜닝은 `06` 1차 통과 후** 별도 sub-phase (예: A-6 또는 Risk Profile B Handoff).

|-----|--------|------|
| **10%** | **40~70%** | 루트 `docs/work_phases/` · `performance_budget_governor` SSOT |

### 4GB RAM 서버 — 코인 메모리 예산 (주식과 공존 시)

서버 **전체 4GB**이면 코인 스택에 **cgroup 상한 필수** (주식 OOM 연쇄 방지):

| 유닛 | 권장 MemoryMax (4GB 서버) | 비고 |
|------|---------------------------|------|
| `dante-bitget-factory` | **768M ~ 1G** | 스캔·pandas 피크 |
| `dante-bitget-ws` | **192 ~ 256M** | |
| `dante-bitget-async` | **96 ~ 128M** | |
| `dante-bitget-dashboard` | **256 ~ 384M** | 필요 시만 기동 |
| `dante-bitget-heatmap` | **192 ~ 256M** | 필요 시만 기동 |
| **코인 합산 목표** | **≤ 1.5 ~ 1.8 GB** | OS + 주식 여유 2GB+ |

```bash
# drop-in 예시 (서버 1회 설정, git pull과 무관)
sudo mkdir -p /etc/systemd/system/dante-bitget-factory.service.d
sudo tee /etc/systemd/system/dante-bitget-factory.service.d/memory.conf <<'EOF'
[Service]
MemoryHigh=700M
MemoryMax=896M
CPUQuota=80%
EOF
sudo systemctl daemon-reload && sudo systemctl restart dante-bitget-factory
```

환경 변수 (`.env` 또는 drop-in): `BITGET_MAX_WORKERS=2~4` (4GB 서버)

## 2. 진단 요약 (왜 Bitget paper가 ‘무인 복리’에 아직 못 미치는가)

> 출처: `bitget/docs/13_institutional_grade_audit_and_roadmap.md` (2026-07)

1. **가상매매만** — 슬리피지·펀딩·실체결 미반영 → 리포트 PnL은 낙관적일 수 있음
2. **Portfolio NAV 서킷브레이커 부재** — 그룹 −30%만 있어 동시 손실 시 계좌 전체 −25%도 통과 가능
3. **deathmatch 자본배분 꺼짐** (`apply_deathmatch_allocation=False`) — 나쁜 전략이 굶지 않음
4. **market key 불일치** (`BG` vs `SPOT`/`FUT`) — 진화·Meta 정합성 약함
5. **tail-risk fund 적립만** — drawdown 시 실제 흡수·트리거 없음
6. **로그 무제한 증가** — 4GB RAM·80GB SSD 서버에서 **수개월 방치 시 디스크 고갈** (P0-1)
7. **24/7 코인** — 장 휴장 없음 → cron 27슬롯·WS·메모리 피크가 **주식보다 지속적** (리소스 cap 필수)
8. **실전 경로 미완** — exit 실주문·funding PnL·parity 없이 `ENABLE_REAL_EXECUTION=true` **금지**

주식 진단(롱 모멘텀 편중·KR 장중 슬롯·MDD 10%)은 **참고만** — Bitget은 **24/7·레버리지·펀딩·WS** 가 추가 변수.

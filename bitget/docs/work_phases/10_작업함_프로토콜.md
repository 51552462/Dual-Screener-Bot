# 작업함 — Bitget Claude ↔ Cursor 기계적 중계 (SSOT)

> **문제**: 채팅에 Handoff/검증이 쌓이면 연속 작업 단절  
> **해결**: **채팅 = 논의** · **`bitget/docs/work_phases/` 파일 = 실행**  
> **멀티 창**: 창 2개가 Bitget을 동시에 하면 MD가 덮어써짐 → **`16_멀티창_레인_프로토콜.md` + `lanes/`** (본문은 레인별, 루트는 표만)

---

## 디렉터 — 매 라운드

```
1. Cursor 세션 끝  → lanes/<레인>/ 본문 + ACTIVE_LANES 행 + 루트 표 + 05 섹션
2. 디렉터          → 09(인덱스) → 해당 레인 09
3. Claude Knowledge — .py 제외 · 레인 OUTBOX만 (또는 Desktop bitget_upload_*)
4. Claude: 「lanes/LANE_XXX/CURSOR_TO_CLAUDE.md 검증. 다른 레인 섞지 말 것.」
5. Cursor: 「레인 LANE_XXX · 해당 Handoff만. 세션 끝 레인 폴더만 쓰기.」
```

---

## 파일 역할

| 파일 | 작성 | 읽기 |
|------|------|------|
| **`lanes/ACTIVE_LANES.md`** | Cursor(자기 행) | **모든 창 첫 확인** |
| **`lanes/<ID>/NEXT_ACTION.md`** | Cursor | 그 창 status |
| **`lanes/<ID>/CURSOR_TO_CLAUDE.md`** | Cursor | Claude(그 레인만) |
| **`lanes/<ID>/09_쉬운요약.md`** | Cursor | 디렉터(그 갈래) |
| **`NEXT_ACTION.md` (루트)** | Cursor | **대시보드 표만** |
| **`09_디렉터_쉬운요약.md` (루트)** | Cursor | **인덱스** |
| **`CLAUDE_TO_CURSOR.md`** | Claude | prepend/append · 삭제 금지 |
| `05_진행로그.md` | Cursor | **섹션 append만** |
| **`16_멀티창_레인_프로토콜.md`** | — | 병렬 창 SSOT |

---

## NEXT_ACTION status

| status | 다음 담당 |
|--------|-----------|
| `WAIT_CLAUDE_HANDOFF` | Claude |
| `WAIT_CURSOR_IMPL` | Cursor |
| `WAIT_CLAUDE_OK` | Claude |
| `WAIT_CURSOR_VPS` | VPS 실행 |
| `WAIT_DIRECTOR` | 디렉터 |
| `SUB_DONE` | 다음 sub |

---

## Cursor — 시작 / 종료

**시작:** ACTIVE_LANES → `lanes/<ID>/NEXT_ACTION` → CLAUDE_TO_CURSOR(내 sub) · **다른 레인 MD 쓰기 금지**

**종료:** `lanes/<ID>/` 네 파일 · ACTIVE_LANES 자기 행 · 루트 인덱스만 · 05 내 섹션

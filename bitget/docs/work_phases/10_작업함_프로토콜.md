# 작업함 — Bitget Claude ↔ Cursor 기계적 중계 (SSOT)

> **문제**: 채팅에 Handoff/검증이 쌓이면 연속 작업 단절  
> **해결**: **채팅 = 논의** · **`bitget/docs/work_phases/` 파일 = 실행**

---

## 디렉터 — 매 라운드 (4단계)

```
1. Cursor 세션 끝  → 05·00·CURSOR_TO_CLAUDE·NEXT_ACTION·NEXT_STEP·09·(11) 저장
2. 디렉터          → **09_디렉터_쉬운요약.md** 먼저 읽기
3. Claude Knowledge 재업로드 (또는 @멘션) — 09·NEXT_STEP 포함 권장
4. Claude 한 줄: 「CURSOR_TO_CLAUDE.md 검증. OK면 09·NEXT_STEP 갱신.」
5. Cursor 한 줄: 「CLAUDE_TO_CURSOR.md 구현만. 세션 끝 09·NEXT_STEP 포함 갱신.」
```

---

## 파일 역할

| 파일 | 작성 | 읽기 |
|------|------|------|
| **`NEXT_ACTION.md`** | Cursor | AI **첫 읽기** (누가 할 일) |
| **`NEXT_STEP.md`** | Cursor·Claude | **디렉터·AI** 다음 한 걸음 |
| **`09_디렉터_쉬운요약.md`** | Cursor·Claude | **디렉터 첫 읽기** (쉬운 말) |
| **`11_협업_효율_점검.md`** | Cursor·Claude | 루프 개선·피드백 |
| **`CLAUDE_TO_CURSOR.md`** | Claude | Cursor 착수 전 |
| **`CURSOR_TO_CLAUDE.md`** | Cursor | Claude 검증 |
| `05_진행로그.md` | Cursor | Claude (누적) |
| `00_전체현황판.md` | Cursor | Claude |

**Handoff/검증 본문 = 파일 only** (채팅 X)

## NEXT_ACTION status

| status | 다음 담당 |
|--------|-----------|
| `WAIT_CLAUDE_HANDOFF` | Claude → CLAUDE_TO_CURSOR |
| `WAIT_CURSOR_IMPL` | Cursor |
| `WAIT_CLAUDE_OK` | Claude |
| `SHADOW_OBSERVING` | 디렉터 (4w 관측) · Claude 다음 Handoff 준비 |
| `WAIT_DIRECTOR` | 디렉터 (Go/No-Go) |
| `SUB_DONE` | Claude → 다음 sub |

---

## Cursor — 세션 시작

1. `NEXT_ACTION.md` — `WAIT_CURSOR_IMPL` 확인
2. `CLAUDE_TO_CURSOR.md` = 유일 spec
3. **bitget/ only** — 루트 주식 diff 금지

## Cursor — 세션 종료

1. `05_진행로그.md`
2. `00_전체현황판.md`
3. `CURSOR_TO_CLAUDE.md`
4. `NEXT_ACTION.md` → `WAIT_CLAUDE_OK`
5. **`NEXT_STEP.md`**
6. **`09_디렉터_쉬운요약.md`** (최신 한 장 — 비개발자용)
7. **`11_협업_효율_점검.md`** (이상·피드백 있을 때)

---

## Claude — 세션 시작

1. `CURSOR_TO_CLAUDE.md` + `05` sub + `00`
2. OK → 다음 Handoff to `CLAUDE_TO_CURSOR.md`
3. 수정 → `CLAUDE_TO_CURSOR.md` 상단 `## Claude 수정 spec`

Custom Instructions 추가:
> Bitget 실행 지시는 CLAUDE_TO_CURSOR.md만. 채팅 Handoff 금지.

> **역할**: Claude Pro = 설계·검증 · Cursor = `bitget/` 구현 · 디렉터 = 승인·복붙  
> **원칙**: sub-phase **하나**씩 · **꼼꼼·정확** O  
> **연결고리**: `bitget/docs/work_phases/05_진행로그.md`  
> **격리**: 루트 `forward/`, `factory_pipelines.py` 등 **수정 금지**

## 한 장 요약 (디렉터용)

```
① Claude Pro  →  sub-phase Handoff (bitget/docs/work_phases/CLAUDE_TO_CURSOR.md)
② 디렉터      →  Cursor Agent에 Handoff 붙여넣기
③ Cursor      →  bitget/ 구현 + 05 + 00 + CURSOR_TO_CLAUDE + NEXT_ACTION + NEXT_STEP + 09 (+ 11)
④ 디렉터      →  **09_디렉터_쉬운요약.md** 먼저 읽기 → Claude Pro에 검증 + **Mirror** 요청
④′ Claude     →  OK/수정 + **ARCHITECT_MIRROR.md** 상단에 능동 의견 (요청만 OK 금지)
⑤ Claude Pro  →  (④′ 포함) OK / 수정 spec → CLAUDE_TO_CURSOR.md
⑥ (2~4주 후)  →  06_검증체크리스트 효과 검증
```

**시너지 핵심**: Cursor = 로컬 구조 **실제 변경** · Claude = 스냅샷 + 목표 대비 **추가 생각**. 둘 다 파일 SSOT.

## 6단계 상세

### 1단계 · Claude Pro — Handoff

- `bitget/docs/claude_project/CAT-HANDOFF_템플릿.md` 형식
- `01~04_묶음*` + `05` + `00` + `@CAT-*` (bitget claude_project)
- 🔴 Critical(F/G/N/D) → 디렉터 승인 문구
- **출력 위치**: `CLAUDE_TO_CURSOR.md` (채팅 Handoff 금지 — `10_작업함_프로토콜`)

### 2단계 · 디렉터 → Cursor

```text
아래는 Claude Pro Bitget Handoff다. 구현만 해줘.
sub-phase: {A-1} · targeted diff only · bitget/ 하위만.
세션 종료 시 bitget/docs/work_phases/05_진행로그.md, 00_전체현황판.md, CURSOR_TO_CLAUDE.md, NEXT_ACTION.md 갱신.
```

### 3단계 · Cursor — 구현

- Handoff 그대로 · sub-phase 1개 · Adapter on conflict
- **금지**: 루트 주식 SSOT 수정, Claude OK 전 Done

### 4단계 · 디렉터 → Claude 검증 + Mirror

```text
@bitget/docs/work_phases/CURSOR_TO_CLAUDE.md @ARCHITECT_MIRROR @05 @00
sub-phase {C-1} Cursor 구현 검증. OK/수정 spec.
+ 로컬 스냅샷을 읽고 ARCHITECT_MIRROR.md 상단에 능동 의견 1~3개 (OK만으로 끝내지 마).
```

### 4.5단계 · Claude Architect Mirror (필수)

- **입력**: `CURSOR_TO_CLAUDE` §로컬 구조 스냅샷 + `00` 갭 표 + `05` 진행
- **출력**: `ARCHITECT_MIRROR.md` 상단 블록 (형식은 해당 파일 헤더)
- **포함**: 중복 모듈 의견 · Layer 2/3 다음 후보 · 북극성 대비 구멍
- **금지**: Mirror로 🔴 live 변경 지시

### 5단계 · Claude OK

| 결과 | 행동 |
|------|------|
| OK | 05에 `Claude OK: 날짜` · **`ARCHITECT_MIRROR` 상단 갱신** · **`09_디렉터_쉬운요약.md` 최신 한 장** · `NEXT_STEP.md` 갱신 |
| 수정 | CLAUDE_TO_CURSOR 상단 `## Claude 수정 spec` |

### 5.1단계 · 디렉터 쉬운 요약 (필수)

- **파일**: `09_디렉터_쉬운요약.md`
- **대상**: 코딩·퀀트 비전문 디렉터
- **Claude OK 시**: Claude도 09 「최신 한 장」을 **쉬운 말로** 덮어쓰기 (기술 검증은 `CURSOR_TO_CLAUDE`에)
- **다음 스텝**: `NEXT_STEP.md` — `NEXT_ACTION`과 항상 같이 갱신

### 5.5단계 · 디렉터 Critical 승인 (묶음A)

- `05` 상단 **Critical 승인 표** — 5건 각 `디렉터 승인: YYYY-MM-DD`
- paper 배포 Go 후 2~4주 paper 시작

### 6단계 · 효과 검증

`06` 표 · paper 2~4주 · MDD 악화 → 롤백

### 6.5단계 · paper 관측 중 병렬 작업 (디렉터 2026-08-02)

- A `06` 수집과 **동시에** Green 등급 sub-phase Handoff·구현 가능
- **Attribution**: NAV/gate/Kelly live 변경은 A 판정 전 🔴
- SSOT: `05` §병렬 작업 · `CURSOR_TO_CLAUDE.md` · Claude 합의 후 `CLAUDE_TO_CURSOR`

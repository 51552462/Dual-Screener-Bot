## C. 항목별 상세 (요약)

### IV-01 룩어헤드
- **있음**: `LOOKAHEAD_BIAS_WARNING_HTML` 매 실행 출력; OOS는 signal→**익일** 수익.
- **없음**: Point-in-time 템플릿·유니버스 (v2 스코프 외).
- **조치**: V-3 PIT; RP-1은 L0만.

### IV-02 생존편향
- **있음**: 30d(KR/US)·14d(BG) 무데이터 강제 청산.
- **없음**: 역사 백테스트용 **시점별 전체 유니버스**.
- **조치**: V-4 PIT universe panel.

### IV-03 거래비용
- **있음**: KR tier 마찰; US ×0.4; OOS -1.5% 강제; BG 3단계 slippage.
- **갭**: 주식 = 모델, 코인 = 실행 감사 — **클록이 쌓이면** L2에서 검증.

### IV-04 과최적화
- **있음**: purged CV·embargo·WF splits 코드.
- **없음**: LIVE 승격 연동; DSR block (`OOS_DSR_MIN` default 0).
- **조치**: V-1 WARN → V-2 BLOCK.

### IV-05 독립 테스트 구간

- **없음**: 파라미터 탐색과 채점 **날짜 분리**.
- **조치**: V-2 config snapshot + immutable holdout.

### IV-06 자기 채점
- **있음**: forward/backtest DB 분리; Claude 설계 / Cursor 구현 분리.
- **없음**: 동일 evolved formula가 RP-1·OOS·승격에 재사용.

### IV-07~08 다중검정·DSR
- Deathmatch·incubator가 수십~수백 trial without deflated metric.
- **조치**: V-2 `evaluate_ledger_deflated_sharpe` promotion hook.

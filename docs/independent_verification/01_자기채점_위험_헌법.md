## 3. 디렉터·AI 공통 금지 목록

1. RP-1 Pass → “CAGR 40~70% 달성 가능” **단정 금지**
2. 백테스트 Sharpe/CAGR만으로 registry LIVE **권고 금지**
3. mutant OOS 합격 = “완전 OOS” **표현 금지** (같은 formula 계보)
4. fast-track PF≥2 **단독**으로 “검증 완료” **금지**
5. Bitget R3 배너 paper 구간 숫자를 Track A와 **직접 비교 금지**
6. shadow job 결과를 production 변경 없이도 “이미 검증됨” **금지** (측정 ≠ 판정)

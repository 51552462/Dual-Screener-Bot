> **역할**: Claude Pro = 설계·검증 · Cursor = 로컬 구현 · 디렉터 = 승인·복붙·최종 판단  
> **원칙**: sub-phase **하나**씩 · 빠르게 X · **꼼꼼·정확** O

## 한 장 요약 (디렉터용)

```
① Claude Pro  →  sub-phase Handoff 프롬프트 작성·검증
② 디렉터      →  프롬프트를 Cursor Agent에 그대로 붙여넣기
③ Cursor      →  구현 + 05_진행로그 + 00_전체현황판 갱신 + 3줄 요약
④ 디렉터      →  요약·diff·05 해당 섹션을 Claude Pro에 전달
⑤ Claude Pro  →  스펙 일치 OK / 수정 spec (OK 전 Done 금지)
⑥ (2~4주 후)  →  06_검증체크리스트 효과 검증 표 갱신
```

---

## 6단계 상세

### 1단계 · Claude Pro — Handoff 프롬프트 작성

**언제**: Cursor 착수 **직전**, sub-phase **하나**만.

**Claude가 할 일**
- 해당 묶음 작업지시서 + `05_진행로그` + `00_전체현황판` + `@CAT-*` 확인
- `docs/claude_project/CAT-HANDOFF_템플릿.md` 형식으로 **Cursor용 프롬프트** 출력
- 로컬 `05`의 **구현 현황**과 충돌 시 Adapter 또는 spec 수정 **먼저**
- 🔴 Critical(F/G/M/K)는 디렉터 승인 문구 포함

**Claude가 하지 않을 일**
- Python 코드 작성 · 레포 파일 직접 수정

**Handoff 프롬프트 필수 포함**
- sub-phase ID (예: `A-3`)
- SSOT 파일·config 키
- 변경 Spec (함수·수식·KR/US)
- Cursor 선독 파일 목록
- 완료 기준 (테스트 힌트)
- **세션 종료 시 `05`·`00` 갱신 지시**

---

### 2단계 · 디렉터 — Cursor로 전달

Handoff **전문**을 Cursor Agent에 붙여넣기.  
맨 앞에 한 줄 권장:

```text
아래는 Claude Pro가 확정한 Handoff다. 판단은 끝났고 구현만 해줘.
sub-phase: {A-3} · targeted diff only.
세션 종료 시 docs/work_phases/05_진행로그.md 와 00_전체현황판.md 반드시 갱신.
```

---

### 3단계 · Cursor — 구현 + 문서 갱신

**할 일**
- Handoff **그대로** 구현 (sub-phase 1개)
- Targeted diff only · 충돌 시 Adapter 제안 또는 Ask
- 세션 **종료 전 필수**:
  1. `05_진행로그.md` — 해당 sub-phase 섹션 (날짜·요약·config 키·파일·잔여)
  2. `00_전체현황판.md` — Phase 표·SSOT 용어집·의존성 체크
  3. 디렉터용 **3줄 요약** (변경 파일·config·테스트 결과)

**하지 않을 일**
- Claude OK 없이 sub-phase **Done** 처리
- 한 세션에 sub-phase **2개 이상**
- 🔴 방어 계층 무분별 전체 rewrite

---

### 4단계 · 디렉터 — Claude Pro에 검증 요청

Cursor 3줄 요약 + `05` 해당 sub-phase 섹션 + (가능하면) 핵심 diff를 Claude Pro에 붙여넣기.

**검증 요청 멘트 예시**

```text
@05_진행로그 @00_전체현황판
sub-phase A-3 Cursor 구현 결과 검증해줘.
Handoff 스펙과 일치하는지 OK/수정 spec 알려줘.
```

---

### 5단계 · Claude Pro — OK / 수정 spec

| 결과 | 다음 행동 |
|------|-----------|
| **OK** | `05` 해당 sub **「Claude OK: 날짜」** 기록 (디렉터 또는 Claude가 05에 한 줄 추가) · 1단계(구현) ✅ |
| **수정 spec** | ① Handoff 수정 → ② Cursor 재실행 (3단계) · **Done 아님** |
| **충돌** | Cursor→Claude 충돌 보고 템플릿 (`CAT-HANDOFF`) · Adapter vs spec 변경 결정 |

**Claude OK = 1단계(구현·스펙 일치) 통과.**  
**진짜 Done = `06` 3단계 전부** (2~4주 가상매매·효과 검증 포함).

---

### 6단계 · 효과 검증 (2~4주 후)

- `06_검증체크리스트_및_실패기록.md` 해당 sub 행 갱신
- MDD 악화 → **무조건 롤백** (`06` 판정 원칙)
- `00_전체현황판` 「가상매매 효과 검증」열 갱신

## 충돌 분기

```
Cursor 구현 중 SSOT 충돌 발견
    → Cursor: Adapter 제안 또는 Ask (코드 무리 적용 금지)
    → 디렉터 → Claude: 충돌 보고
    → Claude: spec 수정 또는 Adapter 승인
    → Cursor: 수정 Handoff로 재실행
```

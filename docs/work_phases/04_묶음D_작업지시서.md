### 입력 (Phase 로그 SSOT — Claude Pro 원문 + 확장)

| 소스 | 데이터 |
|------|--------|
| A | PERF_BUDGET tier/band, KELLY_THROTTLE_*, 쿼터표, WEIGHT_S5, hysteresis |
| B | deathmatch scorecard, STANDBY, GP λ |
| C | PREDICTED_NEXT_SECTOR, spillover lag, (C-3 factor) |

### 출력 — **자유서술 금지** (Claude Pro 원문)

JSON array, schema:

```json
{
  "parameter": "WEIGHT_S4",
  "current": 1.0,
  "suggested": 1.3,
  "reason": "string max 200 chars",
  "confidence": 0.0,
  "market": "KR|US|BOTH"
}
```

- cache: `gemini_report_cache` / `llm_call_cache`

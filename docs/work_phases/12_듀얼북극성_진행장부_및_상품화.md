## 2. 듀얼 트랙 (병렬 북극성)

| 트랙 | 대상 | MDD | 연복리 | 비고 |
|------|------|-----|--------|------|
| **A** | 주식 KR+US | 10% | 40~70% | `performance_budget_governor` |
| **B** | Bitget | 5% | 12~25% (B1~B2) | B0=측정만 |

- **격리**: 리스크 로직·config **공유 금지**. 진행장부만 **읽기 전용**으로 합친다.
- **리더**: 종합점수 = 수익 페이스 60% + MDD 안전 40% (B0는 MDD·데이터 품질만).

## 4. 상품화 게이트 (G0~G4)

| 게이트 | 의미 | 자동 조건 (주간 이력 기준) |
|--------|------|---------------------------|
| **G0** | 측정·구조 | 기본 |
| **G1** | 페이스 형성 | 4주+ · 종합 ≥40 |
| **G2** | 목표 근접 | ≥56일 · avg≥60 · **forward_trades>30** |
| **G3** | 상품화 후보 | ≥84일 · avg≥75 · MDD<캡 · **A06+C2+MDD4주** |
| **G4** | 상품화 Go | **디렉터 수동 승인만** (코드 자동 승격 없음) |

> G3 도달 ≠ 실매매 ON. Bitget은 P2-5 · 주식은 별도 실전 체크리스트.

## 5. 텔레그램

| 항목 | 값 |
|------|-----|
| 봇 | `REPORT_BOT_TOKEN` / `REPORT_BOT_CHAT_ID` |
| 발송 | 단일 HTML — Track A + Track B + 리더 + 게이트 |
| 주식·Bitget 개별 봇과 분리 | 디렉터 **통합 다이제스트** 전용 |

### 실행

```bash
# 일간 (cron 권장: KR daily 18:45 이후 19:30 KST)
./factory.sh --north-star-digest daily

# 주간 (stock weekly 10:05 이후 11:00 KST 권장)
./factory.sh --north-star-digest weekly

# 월간
./factory.sh --north-star-digest monthly

# 미리보기
python scripts/north_star_digest.py --dry-run
```

### cron 예시 (`deploy/factory.kr.crontab.example`)

```
30 19 * * *   ubuntu  cd .../Dual-Screener-Bot && TZ=Asia/Seoul bash ./factory.sh --north-star-digest daily
0  11 * * 6   ubuntu  cd .../Dual-Screener-Bot && TZ=Asia/Seoul bash ./factory.sh --north-star-digest weekly
5  0  1 * *  ubuntu  cd .../Dual-Screener-Bot && TZ=Asia/Seoul bash ./factory.sh --north-star-digest monthly
```

### 일간 `[OBS_HOLD]` + `[쉬운판]` 대시보드 (FWD-OBS-HOLD / NS-DIR-DASH)

일간 digest **맨 앞**에 쉬운 대시보드, 하단에 OBS 패널. **신규 cron 없음.**

| 항목 | 내용 |
|------|------|
| `[쉬운판]` | 목표·n/20 진행바 · ✅잘됨 · ⏳부족 · ⚠️오류 · 📋남은체크 |
| `[OBS_HOLD]` | daily n/20 · gate · `cursor_action` |
| `OBSERVE_HOLD` | n&lt;20 · 관측유지 · mega_trend/목표하향 금지 |
| `RECALL_FORK` | n≥20 · 갈림길 재소집 가능 |
| `---CURSOR---` / `---CLAUDE---` | 디렉터 복붙용 |

규칙: n&lt;20에서 페이스·Pass/Fail·CAGR 확정 금지. SSOT=VPS 원장만.

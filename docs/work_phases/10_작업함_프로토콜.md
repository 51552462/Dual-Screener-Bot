# 작업함 — Claude ↔ Cursor 기계적 중계 (SSOT)

> **문제**: 채팅에 Claude/Cursor 말이 쌓이면 → 디렉터가 **뭘 복붙해야 할지** 모름 → 한 번만 되고 끊김.  
> **해결**: **채팅 = 논의** · **파일 = 실행**. sub-phase마다 **아래 3파일만** 갱신.

---

## 디렉터 — 매 라운드 할 일 (4단계 고정)

```
1. Cursor 세션 끝  → 레포에 05·00·CURSOR_TO_CLAUDE.md 커밋/저장
2. Claude Knowledge에 위 3개 + 본 파일 + CLAUDE_TO_CURSOR.md 재업로드 (또는 @멘션)
3. Claude에게 한 줄만:
   「CURSOR_TO_CLAUDE.md 검증. OK면 CLAUDE_TO_CURSOR.md에 다음 Handoff 작성. 채팅 말고 파일에.」
4. Claude Handoff 확인  → Cursor에게 한 줄만:
   「CLAUDE_TO_CURSOR.md 구현만. 세션 끝에 CURSOR_TO_CLAUDE·05·00·NEXT_ACTION 갱신.」
```

**디렉터가 하지 않을 것**: Claude/Cursor **긴 말 요약 재작성** · 스펙 해석 · 「이것도 해줘」 임의 추가

---

## 파일 역할 (누가 쓰나)

| 파일 | 작성 | 읽기 | 내용 |
|------|------|------|------|
| **`NEXT_ACTION.md`** | Cursor (세션 끝) | **양쪽 첫 읽기** | 지금 누가 · 뭘 · 어떤 sub-phase |
| **`CLAUDE_TO_CURSOR.md`** | **Claude Pro** | **Cursor 착수 전** | Handoff **전문만** (CAT-HANDOFF 형식) |
| **`CURSOR_TO_CLAUDE.md`** | **Cursor** | **Claude 검증 시** | 3줄 요약 + diff 포인트 + 테스트 + **05 섹션 링크** |
| `05_진행로그.md` | Cursor | Claude | 영구 기록 (누적) |
| `00_전체현황판.md` | Cursor | Claude | Phase·SSOT 표 |

**채팅에 Handoff/검증 본문 쓰지 않음** — 반드시 파일.

---

## NEXT_ACTION 상태값

| status | 의미 | 다음 담당 |
|--------|------|-----------|
| `WAIT_CLAUDE_HANDOFF` | Cursor 보고 완료 | Claude → `CLAUDE_TO_CURSOR.md` 작성 |
| `WAIT_CURSOR_IMPL` | Handoff 확정 | Cursor → 구현 |
| `WAIT_CLAUDE_OK` | 구현·05 갱신 완료 | Claude → OK / 수정 spec → `CLAUDE_TO_CURSOR.md` |
| `WAIT_DIRECTOR` | Go/No-Go·Critical | 디렉터 결정 → Claude 또는 Cursor |
| `SUB_DONE` | Claude OK (1단계) | Claude → 다음 sub Handoff |

---

## Cursor — 세션 시작 시 (항상)

1. **`NEXT_ACTION.md`** 읽기 — `status`가 `WAIT_CURSOR_IMPL`인지 확인
2. **`CLAUDE_TO_CURSOR.md`** 전문 = 유일한 구현 spec
3. 채팅/Claude 긴 말 **무시** (파일과 다르면 디렉터 Ask)

## Cursor — 세션 종료 시 (항상)

1. `05_진행로그.md` — 해당 sub 섹션
2. `00_전체현황판.md` — Phase·SSOT
3. **`CURSOR_TO_CLAUDE.md`** — 아래 템플릿
4. **`NEXT_ACTION.md`** → `status: WAIT_CLAUDE_OK`

---

## Claude Pro — 세션 시작 시 (디렉터가 한 줄 보낸 후)

1. **`CURSOR_TO_CLAUDE.md`** + `05` 해당 sub + `00` 읽기
2. 채팅에 길게 쓰지 말고:
   - OK → `CLAUDE_TO_CURSOR.md`에 **다음 Handoff** OR `NEXT_ACTION`만 `SUB_DONE` + 다음 sub Handoff
   - 수정 → `CLAUDE_TO_CURSOR.md` **맨 위**에 `## Claude 수정 spec` 블록 추가 (Cursor가 읽음)

Custom Instructions 추가 권장:
> 실행 지시는 CLAUDE_TO_CURSOR.md에만 작성. 채팅 Handoff 금지. 검증은 CURSOR_TO_CLAUDE.md 기준.

---

## 왜 한 번만 되고 끊기나

| 원인 | 증상 | 이 프로토콜 |
|------|------|-------------|
| Handoff가 채팅에만 있음 | Cursor가 못 찾음 | `CLAUDE_TO_CURSOR.md` |
| Cursor 결과가 요약으로 희석 | Claude가 05와 불일치 | `CURSOR_TO_CLAUDE.md` |
| 「다음 누가」불명 | 디렉터 멈춤 | `NEXT_ACTION.md` |
| Claude OK가 채팅에만 | 05 미반영 | Claude가 OK 한 줄 → 디렉터가 05에 추가 **또는** Claude가 CURSOR_TO_CLAUDE에 OK 블록 |

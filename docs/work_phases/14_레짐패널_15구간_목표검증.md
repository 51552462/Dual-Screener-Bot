## 4. 시뮬레이션 스택 (현 구조 그대로)

RP-1은 **미래 코드가 아니라 오늘 배포 가능한 층**만 켠다:

| 층 | 포함 | SSOT |
|----|------|------|
| S1 공격 | supernova DNA + LIVE/UNDERDOG 템플릿 | `supernova_hunter` · `time_machine_backtester` |
| S4 눌림 | (선택) reverse breakout — 2주 timebox 내 supernova만 먼저 | legacy screener |
| S5 방어 | inverse/blackhole **태그만** — RP-1 v1은 진입 시그널 위주 | A-5a/b 게이트는 **포트폴리오 레벨** 별도 |
| Phase A | Kelly cap · regime ACTION · MDD tier | `meta_governor` · `performance_budget_governor` |
| C-1 | **RP-1 baseline 이후** A/B (있으면 vs 없으면) | C-1 Handoff |

### 알려진 한계 (문서 필수)

1. **Lookahead**: `LOOKAHEAD_BIAS_WARNING` — 현재 템플릿은 “오늘 뇌” → 과거 구간 **낙관 편향**  
2. **RP-1 v1**: 견고성 **하한** 추정 · Pass해도 OOS 재검증 필수  
3. **RP-1 v2** (후속): 구간 종료일 기준 point-in-time 템플릿 — 별도 sub-phase

## 5. 구간별 출력 지표

| 지표 | 목표 대비 | 용도 |
|------|-----------|------|
| **구간 period_return_pct** | 구간 실현 수익 (%) | **판정·리포트 1순위** (짧은 구간에서 연환산 왜곡 없음) |
| 구간 CAGR (연환산) | 40~70% 밴드 | **참고용** — 단독 Pass/Fail 판정 **금지** |
| 구간 MDD | ≤ 10% | **전 bucket** · tier replay 헤드라인 |
| PF · 승률 · n | 참고 | n<30 구간은 **숫자 판정 금지** (ASG 원칙 동일) |
| 진입 0건 | 구조 원인 | “신호 없음” vs “게이트 차단” 분리 |
| Phase A tier 소진 | 로그 재현 | MDD 방어 **기여/과잉** |

> **연환산 CAGR 단독 판정 금지 (Alpha Proof baseline v2.3.3+)**  
> `period_return_pct` / `period_return_pct_raw`를 구간 성과의 **주 지표**로 본다.  
> `cagr_pct`는 기간 길이에 민감한 **보조 지표**이며, BULL_03 등 짧은 구간에서 ±수백% 스파이크가 나와도  
> period_return이 안정적이면 구조 판정을 바꾸지 않는다. North Star 40~70% 밴드는 **장기·다구간 집계**에만 적용.

**Alpha Proof metrics baseline (Claude 확정 2026-08-11)**: `regime_panel_rp1.v2.3.3` — A-3 쿼터 + 국면별 `kelly_cap` tier replay. 산출: `reports/regime_panel/rp1_{date}.json`.

### bucket 합격 (초안)

| bucket | Pass (구조적) | Fail |
|--------|---------------|------|
| 상승 ×5 | **≥3/5** 구간에서 연환산 ≥ 40% **또는** PF>1.3 (n≥20) | 다수 구간 CAGR<20% |
| 횡보 ×5 | MDD ≤10% **유지** · PF≥1.0 | MDD>10% 또는 PF<0.9 다수 |
| 하락 ×5 | MDD ≤10% **유지** · 손실 구간에서 S5/방어 기여 로그 | MDD>10% · 방어 미작동 |

> **전체 North Star Pass**: 3 bucket 모두 Pass + **가중 평균 CAGR** 40% 근접 (Claude 수식 확정)

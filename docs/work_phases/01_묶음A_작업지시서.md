## A-1 · 성과예산 거버너

**CAT**: F · **SSOT**: `performance_budget_governor.py`  
**로컬**: ✅ 파일 존재 · **잔여**: dry-run 테스트, 3단계 효과 검증

### 스펙

- `live_nav_manager.py` NAV/HWM → `current_dd_pct = (HWM - NAV) / HWM × 100`
- MDD 예산 cap = `PERFORMANCE_BUDGET_MDD_CAP_PCT` (기본 **10%**)
- 소진율 = `current_dd_pct / mdd_cap_pct × 100`
- 소진율 구간 → **config_kv SSOT** (다른 모듈 read-only):

| 소진율 | 실제낙폭 | band | kelly_mult | quota_mult | 방어arm | 신규진입 |
|--------|----------|------|------------|------------|---------|----------|
| 0~40% | 0 ~ -4% | NORMAL | 1.0 | 1.0 | off | ALL |
| 40~70% | -4% ~ -7% | CAUTION | 0.5 | **0.6** | on | ALL |
| 70~90% | -7% ~ -9% | DEFENSE | 0.2 | **0.35** | on | TOP_ONLY |
| 90%+ | -9% ~ -10%+ | LOCKDOWN | 0.0 | 0.0 | on | NONE (block) |

### config_kv 키 전체 (SSOT — `00_전체현황판` 동기)

| 키 | 설명 |
|----|------|
| `ENABLE_PERFORMANCE_BUDGET_GOVERNOR` | 킬스위치 (기본 True). False면 neutral tier + block 플래그 무시 |
| `PERFORMANCE_BUDGET_MDD_CAP_PCT` | MDD cap % (기본 10.0) |
| `PERFORMANCE_BUDGET_STATE_KR` / `_US` | 시장별 평가 dict 스냅샷 |
| `KELLY_THROTTLE_MULT_KR` / `_US` | 시장별 Kelly 배율 |
| `KELLY_THROTTLE_MULT` | min(KR, US) 합성 보수값 |
| `POSITION_QUOTA_MULT_KR` / `_US` | 시장별 쿼터 배율 |
| `PERFORMANCE_BUDGET_DEFENSE_ARM_ACTIVE_KR` / `_US` | 방어arm 플래그 (A-5 연동) |
| `PERFORMANCE_BUDGET_BLOCK_NEW_ENTRIES_KR` / `_US` | 90%+ 신규 차단 |

### 설계 주의 (로컬 코드 반영됨)

- `treasury_state.json` **`mdd_pct` 재사용 금지** — monotonic max이므로 "현재" 낙폭과 불일치
- `GLOBAL_CIRCUIT_BREAKER`(일일 -5%)와 **별개** — 누적 HWM 기준
- `catastrophic_day_guard.py`: 확장 vs 신규 → **신규 모듈 채택** (Handoff 결론)
- `ENABLE_KELLY_NAV_DD_OVERLAY=False` — Ch.4 `kelly_elasticity_overlay` NAV축 **비활성**, 본 거버너로 일원화 (패치 D)
- `sync_performance_budget_to_config_kv()` 호출: `meta_governor._step_treasury()`
- A-2 전까지 `forward/shared.py` Kelly chain 직접 수정 **금지**였으나 → A-2는 `meta_governor_consumer`에서 완료

### Cursor 선독

`live_nav_manager.py`, `catastrophic_day_guard.py`, `config_manager.py`, `performance_budget_governor.py`, `meta_governor.py`

## A-4 · 비대칭 히스테리시스

**CAT**: G only · **로컬**: ❌ 미착수 · **🔴 충돌 보고 필요**

### 스펙 (Claude Pro 원문)

- `predictive_regime_ensemble.py` 히스테리시스 **방향 분리**
- **위험 확대** (BULL→HIGH_VOL, BULL→BEAR, SIDEWAYS→BEAR 등): **≤1일**
- **위험 축소/복귀** (HIGH_VOL→BULL, BEAR→SIDEWAYS 등): **2일** (휩쏘 방지)
- transition 방향 테이블 Handoff **필수** (누락 시 구현 금지)

### 로컬 충돌 (Cursor → Claude 보고)

| Claude spec | 로컬 SSOT |
|-------------|-----------|
| 방향별 고정 1일/2일 | `hysteresis_days_f` RL 자가진화 (`HYSTERESIS_EMA_LR=0.5`, 1~5일 클램프, `DEFAULT_HYSTERESIS_DAYS=2`) |
| `HYSTERESIS_DAYS=2` 재정의 | `HYSTERESIS_MIN_DAYS=1`, `HYSTERESIS_MAX_DAYS=5` 이미 존재 |

**제안**: RL 축은 유지하고 **위험확대 transition에만 override=1일** Adapter, 또는 RL 범위를 축소 방향 2일로 bias.
